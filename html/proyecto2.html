Hackathon 1

Descripción

De manera colaborativa se realizo una Landing Page. Esta misma ofrecia un vistazo a la promocion y venta de articulos de natacion como googles, toallas , gorros.

El objetivo principal fue crear una interfaz que facilitara y llamara la atencion de los clientes con nuestros colores y diseños.

Tecnologías

  • HTML
  • CSS
  • JavaScript
  • Bootstrap
  • github

Aprendizaje

Este proyecto permitió el trabajo en equipo y colaboracion continua entre el mismo equipo, como tambien aprender a utilizar el control de versiones de github.
